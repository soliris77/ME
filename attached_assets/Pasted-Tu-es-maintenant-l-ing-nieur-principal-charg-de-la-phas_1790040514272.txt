PHASE 3 — PERFORMANCE
==================================================

Optimise l’application sans modifier son comportement fonctionnel.

Priorités :

1. réduire les re-renders React inutiles
2. mémoriser les calculs coûteux
3. éviter les appels API répétitifs
4. optimiser les listes importantes
5. lazy-load des pages/composants lourds
6. optimiser les composants 3D
7. optimiser les graphiques
8. limiter les animations inutiles
9. nettoyer les listeners
10. nettoyer correctement les timers
11. nettoyer les requestAnimationFrame
12. éviter les memory leaks
13. réduire les recalculs CSS inutiles
14. éviter les gros bundles inutiles

Pour les composants lourds :

- utiliser React.lazy lorsque pertinent
- utiliser Suspense lorsque pertinent
- charger les modules lourds uniquement lorsqu’ils sont nécessaires
- ne pas charger tout le système 3D au démarrage si l’utilisateur n’en a pas besoin

Pour le globe :

- limiter les calculs par frame
- éviter les créations répétées d’objets Three.js
- réutiliser les ressources
- nettoyer correctement textures, géométries et matériaux
- suspendre les animations lorsque le composant n’est plus visible
- respecter prefers-reduced-motion

Pour les graphiques :

- éviter de recalculer toute la série lors d’une simple interaction
- optimiser les tooltips
- limiter les animations coûteuses
- conserver une interaction fluide

==================================================

NE FABRIQUE AUCUNE donnée financière.
